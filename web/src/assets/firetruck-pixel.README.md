# Firetruck map sprite

`firetruck-pixel.png` is an original AI-generated bitmap with a transparent background, created with the imagegen skill in generate mode. It does not copy the supplied watermarked stock image.

Prompt: Original right-facing red 8-bit fire engine with silver ladder, black wheels, blue windshield and roof beacon. Crisp pixel art for a small map marker. Transparent background. No lettering, logos or watermark.

Caller exclamation points are code-native crisp-edge SVGs in `components/mapMarkers.ts`; their colors come from live slack values.
