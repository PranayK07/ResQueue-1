# Wildfire Rescue Queue — intake agent

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

ASI:One resident help desk: request rescue, check queue status, mark safe.

**Try it in ASI:One:** "I need help, there's a fire near me" → fill the form → "status" → "I'm safe".

Requests rescue for residents threatened by a wildfire, shows their live queue position, assigned unit, ETA and the reason, and deletes their location when they are safe or consent expires. Simulated demo — not a replacement for 911.

Part of a multi-agent system coordinating through a shared SpacetimeDB world state.
