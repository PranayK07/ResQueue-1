# Wildfire Rescue Queue — hazard agent

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Owns the hazard picture: fire perimeter (NASA FIRMS / simulated spread), live NWS wind, and the ensemble fire-arrival forecast.

Part of a multi-agent system coordinating through a shared SpacetimeDB world state. Answers the incident commander's fire and weather queries directly.
